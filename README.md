# קטעי טקסט – הריון בסיכון גבוה

אתר אישי שמרכז קטעי טקסט בעברית להעתקה למכתבי סיכום ביקור למטופלות. התוכן מוצפן ונפתח בסיסמה בדפדפן.

## קבצים באתר
- `index.html` – הדף הראשי. **חייב להיקרא בדיוק `index.html`** כדי ש-GitHub Pages יפתח אותו אוטומטית.
- `topics.enc.js` – התוכן המוצפן (כל הנושאים והטקסטים). נוצר מקומית מתוך `topics.js` בעזרת `encrypt.py`.
- `docs/` – כספת מסמכי PDF. כל קובץ כאן מוצפן (`*.pdf.enc`) ומנוהל מהדף "מסמכי PDF" באתר.

## עדכון תוכן
1. עורכים מקומית את `topics.js` (הקובץ הלא-מוצפן, **לא נמצא ברפו ואסור להעלות אותו**).
2. מריצים `python3 encrypt.py` ליצירת `topics.enc.js` חדש.
3. ב-`index.html` מעלים את מספר הגרסה בשורה `topics.enc.js?v=N`.
4. מעלים לרפו את `index.html` ואת `topics.enc.js` (Add file → Upload files → לגרור → Commit changes).

האתר מתעדכן אוטומטית תוך דקה-שתיים.
