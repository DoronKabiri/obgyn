# קטעי טקסט · הריון בסיכון גבוה

אתר אישי שמרכז קטעי טקסט בעברית להעתקה למכתבי סיכום ביקור למטופלות. התוכן מוצפן ונפתח בסיסמה בדפדפן.

## קבצים באתר
- `index.html`: הדף הראשי. **חייב להיקרא בדיוק `index.html`** כדי ש-GitHub Pages יפתח אותו אוטומטית.
- `topics.enc.js`: התוכן המוצפן (כל הנושאים והטקסטים). נוצר מקומית מתוך `topics.js` בעזרת `encrypt.py`.
- `docs/`: כספת הקבצים (כל סוג קובץ, עד 15 מגה-בייט לקובץ). כל קובץ כאן מוצפן (`*.enc`) ומנוהל מהדף "מסמכים (כספת מוצפנת)" באתר.

## מה יש בדף
- **שדות מילוי בתוך הטקסט**: כל סוגריים מרובעים (כגון [שם], [XX], [ראש/עכוז]) וסימונים כמו XX, YY, ZZ+W, DD.MM.YYYY הופכים לשדה קטן או לכפתורי בחירה. תווית עברית זהה (למשל [שם]) משותפת לכל הנושאים באותו ביקור. בהעתקה הדף שואל אם נותרו שדות ריקים. הערכים נשמרים בזיכרון בלבד ונמחקים ב"מטופלת חדשה" או ברענון.
- **סרגל ביקור** (מתחת לכותרת): תאריך לידה משוער או שבוע היום, משקל וגובה. ממלא אוטומטית שבוע ותאריך בטקסטים ובמחשבונים, ומציג "מועדים קדימה" עם טווחי תאריכים לבדיקות שנותרו (אפשר להעתיק כבלוק).
- **העתקה נקייה**: כל העתקה מסירה תווי כיווניות ורווחים כפולים כדי להידבק נכון ברשומה הרפואית.
- **נעוצים וחבילות**: "נעץ" מעלה נושא לראש התפריט עם קיצור Alt+מספר. במכתב המאוחד "שמור כחבילה" שומר צירוף נושאים בשם, לשימוש חוזר מהתפריט. תוצאת מחשבון אפשר להוסיף למכתב המאוחד בלחיצה.
- **הצג למטופלת**: תצוגה גדולה של השיחה, התוכנית וסימני האזהרה, עם איורי 100 נשים בנושאים נבחרים, ו"הדפס עלון".
- **אישורים**: קבוצה של תבניות לאישור טיסה, אישור נוכחות, מכתב התאמות למעסיק והפניה למיון.
- **שמירת הריון**: בנושאים הרלוונטיים בלוק מקופל עם נימוק רפואי לאישור, להעתקה בנפרד.
- **בדיקת הבנה**: בסוף נושאים נבחרים שאלות חזרה ונקודות להסבר בעל פה, לרופא בלבד (לא מועתק ולא מודפס).
- **הערות ומונים**: תיבת הערות לכל נושא ומוני צפייה והעתקה, מסונכרנים מוצפנים דרך שירות ההעלאה.

## עדכון תוכן
1. עורכים מקומית את `topics.js` (הקובץ הלא-מוצפן, **לא נמצא ברפו ואסור להעלות אותו**).
2. מריצים `python3 encrypt.py` ליצירת `topics.enc.js` חדש.
3. ב-`index.html` מעלים את מספר הגרסה בשורה `topics.enc.js?v=N`.
4. מעלים לרפו את `index.html` ואת `topics.enc.js` (Add file → Upload files → לגרור → Commit changes).

האתר מתעדכן אוטומטית תוך דקה-שתיים.
