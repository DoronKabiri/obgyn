# קטעי טקסט – הריון בסיכון גבוה

אתר אישי שמרכז קטעי טקסט בעברית להעתקה למכתבי סיכום ביקור למטופלות.

## קבצים באתר
- `index.html` – הדף הראשי. **חייב להיקרא בדיוק `index.html`** כדי ש-GitHub Pages יפתח אותו אוטומטית.
- `topics.js` – הנתונים (כל הנושאים והטקסטים). מתעדכן בהמשך.

## עדכון תוכן
לעדכון נושאים — להחליף את `topics.js` בקובץ חדש (Add file → Upload files → לגרור את הקובץ → Commit changes).
האתר מתעדכן אוטומטית תוך דקה-שתיים.
